# Практика по ООП на Python

Набор практических задач для изучения **объектно-ориентированного программирования (ООП)** на языке Python.

В задачах постепенно рассматриваются классы и объекты, инкапсуляция, наследование, переопределение методов и полиморфизм.

## Цель проекта

Практически изучить основные концепции ООП в Python и научиться:

* создавать классы и объекты;
* работать с атрибутами и методами;
* использовать конструктор `__init__`;
* применять инкапсуляцию;
* создавать дочерние классы;
* использовать наследование;
* переопределять методы;
* применять полиморфизм;
* использовать `super()`;
* соблюдать принцип DRY.

## Задачи

### 1. Класс `Cat`

Создаётся класс `Cat`, описывающий кота.

Каждый объект содержит:

* `breed` — порода;
* `name` — имя;
* `age` — возраст.

Создаются три объекта с разными данными и выводится информация о каждом коте.

**Изучаем:** классы, объекты, атрибуты, `__init__`, `self`, методы.

### 2. Класс `Car` и инкапсуляция

Создаётся класс `Car` с температурой двигателя.

Атрибут `_engine_temperature` хранит температуру двигателя.

Метод `start_engine()` прогревает двигатель до `90` градусов.

Метод `drive()` проверяет температуру и разрешает движение только после прогрева двигателя.

**Изучаем:** атрибуты с `_`, методы, `if / else`, изменение состояния объекта.

### 3. Класс `Graph`

Создаётся класс `Graph`, который хранит координаты и масштаб.

Атрибуты:

* `_x` — координата X;
* `_y` — координата Y;
* `_scale` — масштаб.

Методы:

* `move(dx, dy)` — перемещение;
* `change_scale(factor)` — изменение масштаба.

Создаются три объекта и изменяются независимо друг от друга.

**Изучаем:** изменение состояния объектов, `+=`, `*=`, работу с несколькими объектами.

### 4. Базовый класс `Figure`

Создаётся родительский класс `Figure`.

Общие свойства фигуры:

* `coords` — координаты;
* `width` — ширина;
* `color` — цвет.

Общие данные помещаются в родительский класс, чтобы не дублировать код в дочерних классах.

**Изучаем:** базовые классы и принцип **DRY**.

### 5. Наследование: `Line`, `Rect`, `Ellipse`

Создаются дочерние классы:

* `Line`;
* `Rect`;
* `Ellipse`.

Все они наследуются от `Figure`.

Дополнительные свойства:

* `Line` → `length`;
* `Rect` → `height`;
* `Ellipse` → `radius`.

Для вызова конструктора родительского класса используется `super()`.

**Изучаем:** наследование, дочерние классы, `super()`.

### 6. Полиморфизм и метод `draw()`

В `Figure` добавляется метод `draw()`.

Каждый дочерний класс переопределяет этот метод и выводит собственное сообщение.

Например:

```text
Рисуется линия
Рисуется прямоугольник
Рисуется эллипс
```

Все фигуры помещаются в один список и обрабатываются одним циклом:

```python
for figure in figures:
    figure.draw()
```

**Изучаем:** переопределение методов и полиморфизм.

### 7. Добавление `Triangle`

Добавляется новый класс `Triangle`, который наследуется от `Figure`.

Он переопределяет метод `draw()`.

При этом существующий цикл менять не нужно:

```python
for figure in figures:
    figure.draw()
```

**Изучаем:** расширяемость программы и полиморфизм.

### 8. Инкапсуляция координат и вычисление площади

Координаты фигуры становятся скрытым атрибутом:

```python
__coords
```

Для доступа используются методы:

* `get_coords()`;
* `set_coords(coords)`.

Создаются классы:

* `Circle`;
* `Square`.

Оба класса реализуют метод `calculate_area()`.

Для круга используется формула:

```text
S = π × r²
```

Для квадрата:

```text
S = a²
```

**Изучаем:** инкапсуляцию, getter/setter, наследование и полиморфизм.

## Основные принципы ООП

| Принцип              | Примеры                                                   |
| -------------------- | --------------------------------------------------------- |
| **Классы и объекты** | `Cat`, `Car`, `Graph`, `Figure`                           |
| **Инкапсуляция**     | `_engine_temperature`, `__coords`                         |
| **Наследование**     | `Line`, `Rect`, `Ellipse`, `Triangle`, `Circle`, `Square` |
| **Полиморфизм**      | `draw()`, `calculate_area()`                              |
| **Переопределение**  | собственный `draw()` у фигур                              |
| **`super()`**        | вызов конструктора `Figure`                               |
| **DRY**              | общие свойства находятся в `Figure`                       |

## Как запустить проект

### Требования

Для запуска проекта понадобится:

* **Python 3.x**
* любой редактор кода, например VS Code, PyCharm или другая IDE.

Проверить установленную версию Python можно командой:

```bash
python --version
```

или:

```bash
python3 --version
```

### Запуск отдельной задачи

Перейдите в папку проекта:

```bash
cd путь/к/проекту
```

После этого запустите нужный `.py` файл:

```bash
python task1.py
```

Например, для девятой задачи:

```bash
python task9.py
```

Если в системе используется команда `python3`:

```bash
python3 task9.py
```
